# 使用进程级发送授权并自动恢复页面等待

求职者一次确认后武装当前 JobPilot 进程，授权覆盖后续搜索方案、开场模板和额度变化，并可连续手动启动任意数量的真实投递批次，不设置进程累计沟通额度，也不要求逐批再次确认；求职者可以通过 UI 主动结束授权，进程结束时授权也会失效，不另设环境级强制只读开关。UI 无法使用时，关闭 JobPilot 进程是最后的受支持停止方式，遗留操作按结果未知恢复。每次手动启动批次前仍展示当前页面账号名称、搜索方案、模板预览、批次额度和待核实数量；控制台持续显示本进程累计额度、自动成功、结果未知和内容不符。批次页面在页面连接仍有效时不再活动或可见，尚未开始的下一次沟通无限期等待，页面恢复活动可见后经过正常命令目标校验并自动继续；页面或扩展断线会终止当前批次，但不撤销发送会话授权，求职者重新连接后可以手动启动新批次。授权页展示扩展尽力读取的页面账号名称，但名称未知不阻止授权。本决定以一次确认覆盖内容可变化且累计后果不设上限、陈旧批次可能在长时间等待后恢复，以及缺少独立强制只读开关为代价，换取连续批次运行时更少的人工确认与中断。
