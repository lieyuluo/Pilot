# 使用用户主动的一步页面就绪流程

本决策取代 ADR-0010 中的“人工持久配对”和协议 v1 只读兼容策略，保留其余 WebSocket、安全边界、单连接和命令幂等决定。首次连接不再要求求职者跨扩展弹窗与 JobPilot 设置页核对六位配对码；求职者在目标 BOSS 标签页打开固定来源的扩展并点击“连接并检查当前页面”，即明确授予扩展授权，服务端随后通过版本化 WebSocket 串行完成授权、页面连接和只读校准，并只在三者全部成功后报告页面就绪。流程继续限制在本机回环地址、单扩展和单批次页面，保留持久配对密钥、协议与能力校验、批次运行期拒绝、阶段化错误和幂等重试，不放宽管理页 Origin 或 CSRF 防护，也不建立发送会话或发送消息；这以取消跨界验证码的人工作证为代价，换取首次及后续均由一次明确用户操作完成的连接体验。
