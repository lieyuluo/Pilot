# 每次沟通使用一个持久原子命令

本机服务拥有搜索方案与候选队列，只有取得 Boss 职位 ID 或规范化职位 URL 时才允许真实发送；在第一次外部页面动作前重新读取并评估职位、持久记录沟通操作及预占沟通额度，再向扩展发送一个绑定职位、消息摘要、连接、标签页和六十秒截止时间的原子命令。扩展在该命令内完成目标校验、点击沟通、填写消息、发送和结果证明。读取与导航在每次重检连接、目标和截止时间后最多重试两次，不可逆步骤绝不重试。动作前基线之后新增的本人侧消息与最终消息完全一致时确认沟通成功；平台明确返回沟通成功弹窗时也确认成功，并按 ADR-0014 尽力进入聊天追加模板。若两类成功证据均不存在且平台产生其他本人侧消息，则不再发送模板并记为内容不符。第一次点击前得到的明确未开始会返还额度但同批不自动重试，连续三次则人工接管；点击后超时或中断均为结果未知，不使用含混的“明确失败”终态。批次处理完队列但存在结果未知或内容不符时，以已完成有异常结束。普通停止等待当前命令结束，紧急停止只能阻止后续步骤：不可逆动作已经开始时必须记为结果未知。本机数据库使用只追加事件保存权威操作账本，扩展在 `chrome.storage.local` 保存命令终态，重复命令只返回原结果；人工核实追加新事件而不覆盖原自动结果或批次总结。本机永久防重记录仅保存职位标识、操作与命令 ID、模板 ID、渲染消息摘要和长度、结果及必要时间，不保存消息正文；详细动作诊断仅保存结构化阶段、选择器结果、耗时和错误分类，保留十四天后删除，不保存截图、完整 HTML、聊天文本或招聘者资料。待核实职位只在批次结束后处理，求职者打开对应职位会话并由系统复核职位身份后，结合当时摘要、时间和结果选择人工确认已发送、人工确认未发送或仍无法判断。配置与职位快照导出时包含永久最小事件和人工核实结果，但排除详细诊断、消息正文、扩展配对秘密和页面账号名称。本决定以更复杂的双端持久状态机和分层保留为代价，换取双方任一重启后的防重、明确的不可逆边界和有限的数据暴露。
