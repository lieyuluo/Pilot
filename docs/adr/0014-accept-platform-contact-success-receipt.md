# 接受平台沟通成功回执并尽力追加模板

Boss 可能先代发默认招呼并弹出“已向BOSS发送消息”，此时要求模板完全匹配会把平台已经确认的沟通误记为内容不符或结果未知。系统因此把位于同一可见弹层内、同时包含成功标题和继续沟通入口或招呼语设置提示的界面视为独立成功证据；招呼语设置提示兼容“设置招呼语”和“设置打招呼语”文案，成功标题、提示正文与继续沟通入口可以分处弹层的不同子容器，但不得仅凭页面正文中的相似文本确认成功。识别后尽力点击“留在此页继续沟通”并自动发送当前开场模板，但进入聊天、填写、发送或二次确认失败都不撤销已经成立的沟通成功。审计证据必须区分模板消息匹配与平台成功回执，只有前者记录模板消息摘要；若成功后出现登录失效或验证风控，该候选职位仍记成功，批次随即交由人工接管。
