# 真实 Boss 页面改用 Chrome 扩展

真实 Boss 页面只由求职者安装在独立 Chrome 配置中的 Manifest V3 扩展读取和操作，求职者人工登录并为每个投递批次明确连接唯一标签页；JobPilot 不再启动或通过 Playwright、CDP、`chrome.debugger` 控制真实浏览器。规则、批次状态和不可逆动作判定仍由本机服务拥有，扩展只充当受限的页面观察者和原子动作执行器；Playwright 仅保留给本机管理页面和脱敏 HTML 夹具测试。本决定以较高的扩展安装和连接复杂度，换取正常 Chrome 登录环境、明确的页面授权以及移除专用自动化浏览器检测面的能力，并取代 ADR-0002 和 ADR-0003。

## Consequences

- JobPilot 不提供“打开专用浏览器”，也不持有或迁移 Chrome 登录资料。
- 页面连接在批次完成、停止、人工接管、标签页关闭、离开平台或账号变化时失效。
- 扩展使用隔离世界和标准 DOM 能力；需要调试器、主世界私有 API 或平台检测规避时停止，而不升级权限。
- 扩展先交付只读能力，再验证五次由求职者逐次确认的单职位真实沟通，最后才开放二十个职位的有人值守批次。
