# 通过受限真实批次逐步开放完整额度

真实发送直接复用正式投递批次管线，不建立独立的单职位发送流程；扩展只声明 `read` 和 `batch-send`，验证额度完全由本机服务控制。最初仅允许运行只有一个沟通额度的验证批次，取得五次验证成功且待核实队列为空后自动开放二十个沟通额度，且该资格对本机安装永久有效，不因账号、页面、模板或适配器变化失效，但求职者可以主动重置。待核实职位不阻止启动后续验证批次，只阻止资格生效。任何进入不可逆步骤的动作都会消耗沟通额度，结果未知的职位在人工核实前不得再次发送；但只要账号、页面连接和 DOM 读取仍健康，局限于单个职位的结果未知不会终止批次，即使同一批次重复出现也继续处理其他职位。本决定以扩大自动确认故障时的未知结果数量、并让既有验证结果覆盖未来账号与适配器为代价，换取发送管线只有一种架构、避免单个职位阻断整个批次，并且资格无需反复重建；它取代 ADR-0008 中五次独立单职位确认后再开放批次的推进方式，以及 ADR-0004 中首个结果未知即暂停整个批次的要求，但不改变结果未知职位不得自动重试的约束。发送授权的生命周期另见 ADR-0012。
