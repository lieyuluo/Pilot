# Chrome 登录资料不归 JobPilot 管理

求职者通过 Chrome 原生界面手动创建专用于 JobPilot 的浏览器配置，并在其中安装扩展和人工登录；Chrome 配置、Cookie、登录令牌和原始账号标识不进入 JobPilot 应用目录、配置导出或迁移流程。JobPilot 只在 SQLite 中保存用户确认的账号显示名称、可用稳定标识的本地哈希、扩展配对信息、职位快照和最多保留十四天的脱敏结构化诊断；旧 Playwright 浏览器配置升级后不自动删除或导入，以牺牲自动迁移换取凭据所有权和删除边界清晰。本决定取代 ADR-0005，同时保留本地 API 仅监听回环地址和敏感数据不得导出的约束。
