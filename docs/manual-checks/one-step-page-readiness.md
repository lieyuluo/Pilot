# 一步页面就绪手工检查

只使用本人账号和本人明确选择的 BOSS 标签页执行。不要在自动化测试中访问真实 BOSS。

1. 构建并重新加载 `dist/extension`，启动 JobPilot，启用至少一个搜索方案。
2. 在已登录的 BOSS 标签页打开扩展，确认按钮为“连接并检查当前页面”，且旁边明确说明不会发送消息。
3. 点击一次按钮，关闭扩展弹窗后重新打开；确认流程仍在后台继续，且阶段依次显示连接本机、授权、连接页面、检查页面和返回搜索列表。
4. 确认成功状态为“页面已就绪”，JobPilot 已切换到 Boss 真实页面模式，设置页显示同一结果，总览允许进入批次确认，但没有自动建立发送会话或发送消息。
5. 再次打开扩展，确认不会重新校准已就绪的同一页面。
6. 分别验证没有启用方案、未登录、验证或风控页面、非 BOSS 标签页、已有另一页面连接、批次运行中和旧扩展版本；每种情况都应停在明确阶段，不抢占、不发送消息，并可在修复条件后使用同一按钮重试。
7. 解除页面连接并重启 JobPilot；确认扩展授权仍可复用，但必须再次从目标 BOSS 标签页点击按钮建立页面连接和校准。
